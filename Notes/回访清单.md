## 入库门槛（四条全过）

1. **亲手写过**（没写过 = 假账，进归档，不进这里）
2. 答错会**静默**写 bug（当场 `SyntaxError` / `TypeError` 的不要）
3. **一句话可复测**（"了解即可"的不要）
4. **三个月内用得上**（方向 = LLM 应用：网络 / JSON / async / 异常 / 成本）

> **不进判据的东西**：版本号 / 字节数 / 毫秒数 / 容量阶梯 —— 记错也不改变写法。
> **判据要写清边界**：`sort()` 返回 `None` 是"只改不取"那批方法的约定，**不能**说成"原地改一律返回 None"（`pop()`、`+=` 是反例）。
