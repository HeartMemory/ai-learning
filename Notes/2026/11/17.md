# 2026-11-17（周二）· L1 关卡 2：交叉熵不是「算个分」，是「把概率换算成可比的平均惊讶度」

## 三句话复盘

1. **最大收获**：交叉熵 = `-(1/N)Σ log2 P`，三个数一路递减 —— 基线 **7.3038** > unigram **6.7141** > bigram **1.2943**（bits/char，困惑度 158 → 105 → **2.45**）。**V 必须取训练集的 158，不是全语料的 180**：22 个字只出现在留出集里，拿它们算基线等于作弊。
2. **最大教训**：**判据要能抓「量算错了」和「事没测到」两类错，而这两类要分开管**。留出集判据只问「skip 值有没有升高」，于是 **`math.log2` 写成 `math.log` 时它照样绿**（两边一起除以 2.303，序和升高都成立），最后是「两路互证」（逐位置 vs 按对加权，差 < 1e-12）抓出来的。反过来，互证抓不到「稀疏」这种**事实** —— 那得靠 `inf` 证据和 79.8% 未见对。
3. **明天第一步**：L1 关卡 3（softmax）—— 平移不变（全体加常数 c，输出差 < 1e-12）+ 溢出对照（`[1000.0, 0.0]` 直接 `exp` 抛 `OverflowError`，先减 max 再算则正常）。

## 今日沉淀

| 领域 | 内容 | 关键判据（可复测） |
|---|---|---|
| **交叉熵的定义** | `-(1/N)Σ log2 P(字)`，N = 评估文本的**位置数**（每个位置一个样本，同字出现 3 次算 3 次） | `ce_unigram('面包面包猫','猫面包')` = **1.6553**（`-(log2 0.2 + 2·log2 0.4)/3`） |
| **两路互证（unigram）** | 逐字路 `-(1/N)Σ log2 P(c)` ≡ 频次路 `-Σ p log2 p` | 差 **0.0**；训练集 **6.7141** = 分布自身的熵 |
| **两路互证（bigram）** | 逐位置路 ≡ 按对加权 `-Σ (k/M) log2(k/row_totals[a])`，M = `len-1` | 差 **0.0**；训练集 **1.2943**。这条是今天补的，**没有它「分母写错」抓不到** |
| **困惑度** | `ppl = 2^CE`（底数必须与 log 底配对）；含义 = 每一步平均在几个字里犹豫 | 基线 158.00 / uni 104.99 / bi **2.45** / 留出集（只算见过的对）3.23 |
| **留出集的意义** | 同一个函数 `ce_*(train, eval_text)`：`eval_text = train` 是「自己考自己」，`= held` 才是考试 | train 337 / held 85；默认口径两个模型都 **`inf`** |
| **`inf` 与 `nan` 的区别** | `inf` = 模型说不可能（有信息）；`nan` = 压根没测到（评测失效） | 留出集 22 个新字、67/84 = **79.8%** 未见对 → `inf`；`""` / 单字 → `nan` |
| **跳过未见位置会「变好看」** | `skip_unseen=True` 把最难的题划掉 ⇒ 留出集 **6.5798 < 训练集 6.7141**（unigram） | 所以默认口径**不许**悄悄跳过；skip 只能当「有限可比的辅助数字」，且要报漏了多少 |
| **分母跟着口径走** | 跳过 k 个位置后分母 = 真正算到的位置数 | 分母错成 `len-1` ⇒ 留出集 CE **1.6935 → 0.3427**（「比训练集还好」）→ 判据红 |
| **未见有两种形态（bigram）** | ① 对不在 `counts` 里 ② `prev` 不在 `row_totals` 里（语料**最后一个字**从没当过 context） | `totals` 键类型是 `str`、`counts` 键类型是 `tuple`，两种查找不能混 |
| **跳过 ≠ 删字** | 删字会把左右邻居凑成原文里不存在的对（`abcde` 删 `c` ⇒ 凭空出现 `(b,d)`） | 真实语料里恰好没撞上 ⇒ 变异**一度是绿的**；用 `tiny_train="adbc"` / `eval="axd"`（正解 `nan`，删字法 `0.0`）才抓住 |
| **`[] == 0` 是 `False`** | 空容器判空不能写 `== 0`，守卫形同虚设 | 空串/单字掉到 `0.0 / 0` → `ZeroDivisionError`（重构前是 `nan`）|
| **`itertools.pairwise`** | 3.10+；产出 n−1 个相邻对；**返回迭代器**，`len()` 抛 `TypeError`、遍历第二次为空 | `list(pairwise('abcd'))` = 3 对；替掉 `range(M)` + 下标后，**越界那类 bug 从结构上消失** |
| **守卫看模型、不看原文** | `char not in probs` vs `char not in train`，现在等价（`set(probs) == set(train)`） | 关卡 4 加平滑 / `<UNK>` 后就分家：用原文判会提前 `return inf`，把平滑白做 |
| **`str` 不可变 ⇒ 循环里「改」是重新绑定** | `for ch in s:` 迭代的是**最初那个对象**，循环体里 `s = s.replace(...)` 只换名字 | `'abbc'` 逐字删：进过循环体 **4 个字**；`list` 版边遍历边 `remove` 只进 3 个（漏掉第二个 `b`） |
| **函数签名里的 `*`** | 关键字参数分隔符，其后的参数必须带名传 | `ce_unigram('a','b',True)` → `TypeError: takes 2 positional arguments but 3 were given` |
