# 2026-11-05（周四）· S0 收口：装饰器是 def 时的调用，闭包记住的是变量，`from None` 切的是显示

## 三句话复盘

1. **最大收获**：把「装饰」这件事拆干净了 —— `@timer` 就是 `f = timer(f)`，**在 `def` 那一刻执行完**，函数还没被调用；`timer(add)` 只造替身（实测返回 `timer.<locals>.wrapper`，**不调真身**），第二段括号才真正调。而替身能包住任意函数靠的是 `*args` / `**kwargs`（定义处打包、调用处拆包），能"不露馅"靠的是 `functools.wraps`（六属性 + `__wrapped__`）。顺带看清：`inspect.signature` 恢复签名**不是复制**，是顺着 `__wrapped__` 找到真身。
2. **最大教训**：**变异测试自己也会假绿** —— 第一次拿 `text.upper()` 当变异，结果没变红，因为 `"中文测试".upper()` 还是 `"中文测试"`（中文没有大小写）。"我改过了"不等于"行为变了"；同时 `write_text` 不给 `encoding` 也抓不到，因为同机往返用的是同一个默认编码 —— 判据必须**下沉到字节层**（`read_bytes() == text.encode("utf-8")`）才把这两条变异逼红。
3. **明天第一步**：**S0 交付物**（并发抓取 + 存 JSON + 类型注解 + README），死线 **11-06 不动**。今天 D3/D5 补齐 ⇒ S0 语言层四条判据都有实测依据，交付物的发动机（`httpx` + `asyncio.gather` + `json` + `pathlib`）全在手上了；**唯一残留缺口 = `import` 与模块查找**（D3 只覆盖了"函数作为值"那半边，已记进 Python 册第 9 章与附录，明天交付物分文件时顺带补）。

## 今日沉淀

| 领域 | 内容 | 关键判据（可复测） |
|---|---|---|
| **`@deco` 的本质** | 语法糖 = `f = deco(f)`，**在 def 时求值**；`@a @b` ≡ `a(b(f))`，自下而上 | `timer(add)` 返回替身、真身**未执行**；两段调用才见计时行 |
| **替身三件事** | 接住任意参数 → 展开传给真身 → **return 交回返回值**（+ 不许吞异常） | `calling(2, 3)` → `5`；`calling(2, 3, scale=10)` → `50` |
| **少一个星号** | 定义处 `*args` 是"收"，调用处 `*args` 是"拆" | 写成 `fn(args)` ⇒ tuple 当第 1 个位置参 ⇒ `TypeError` |
| **收下却忘转发** | `fn(*args)` 漏 `**kwargs` ⇒ `scale` 回默认 1 | **静默返回 5**（不报错），靠 `5` vs `50` 才逼得出来 |
| **`functools.wraps`** | `wraps(fn)` 返回装饰器（`partial(update_wrapper, ...)`），必须带 `(fn)` | `__name__` `'wrapper'`→`'add'`、`__doc__` `None`→原文、`__wrapped__` 出现、`signature` 含 `scale` |
| **版本差异** | 3.14.8 的 `WRAPPER_ASSIGNMENTS` 是 **`__annotate__`**，不是文档常写的 `__annotations__`（PEP 649） | `Lib/functools.py:32-33` 实测 + 属性打印 |
| **闭包晚绑定** | 带走的是**变量盒子**不是值 ⇒ 三个闭包共用一个 `i` | `[6, 6, 6]`；默认参数钉死 ⇒ `[2, 4, 6]`；ruff **B023** 自动抓 |
| **观测"何时发生"** | 需要一条时间线：模块级 `EVENTS` + 装饰时/调用时各 append 一笔 | `def` 之后 `EVENTS` 已有"装饰"那笔、**没有**"调用"那笔 |
| **异常三态** | `from exc` / 裸 `raise` / `from None` 只差 `__cause__` 与 `__suppress_context__` | 显式：`cause` 是 `ValueError` 且 `suppress` True；裸 `raise`：`cause` None、`context` 非空、`suppress` False |
| **`from None`** | 切的是**显示**，不是记录：`__context__` 里原异常还在 | `cause is None` + `suppress is True` + **`context is not None`** 三者同时成立 |
| **`B904`** | `except` 里 raise 不带 from 会被 ruff 抓；故意隐式链要 `# noqa: B904` | 同一行写 noqa 才生效（诊断挂在 `raise` 那行） |
| **`pathlib`** | `/` 等价 `joinpath`、每次产生新 Path；`write_text` **不建目录** | `p == root.joinpath("notes", "day.txt")` 为 True；不 mkdir ⇒ `FileNotFoundError` |
| **`write_text` 返回值** | 是**字符数**不是字节数 | `"中文abc"` → **5**（UTF-8 实写 9 字节） |
| **绝对路径重置** | `root / "/abs"` 前面整段被丢，Windows 上**盘符保留** | `(root / "/abs").name == "abs"` |
| **encoding 判据的层次** | 同机往返抓不到"不给 encoding"，必须下沉字节层 | `path.read_bytes() == text.encode("utf-8")`；变异"gbk 写"变红 |
