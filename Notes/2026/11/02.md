# 2026-11-02（周一）· S0 缺口补完：推导式 / 切片 / 迭代器

## 三句话复盘

1. **最大收获**：三块缺口其实是同一条根 ——「容器操作分三层，各层有自己的坑」：**推导式管造**（`if` 位置决定语义：后置 = 过滤、前置三元 = 分流，同输入 `[1,2,3]` 长度 **1 vs 3**）、**切片管取**（**永远返回新容器**，但装的是原元素的**引用** ⇒ 整段切片 = 浅拷贝）、**迭代器管走一遍**（**一次性**，走完再走是空，且不报错）。
2. **最大教训**：**判据必须写精确期望值，写"非空"等于没验**。`Countdown.__next__` 把停止条件写成 `self.current <= 1`，产出 `[3, 2]` —— **少了一个值，没有任何异常或警告**，只有 `assert list(Countdown(3)) == [3, 2, 1]` 这条精确序列抓得住。同一类病还有两处：`even_squares` 里多余的 `if not nums`（把"空输入天然安全"这件事从判据里抹掉了）、以及把 `item["id"]` 改成 `item.get("id")`（把 `KeyError` 洗成静默覆盖）。
3. **明天第一步**：**`httpx`** —— 它是 S0 交付物（并发抓取 + 存 JSON）唯一的发动机，属于**无镜子**的新 API，按既定口径**先查官方文档再动笔**；判据 = 并发抓 N 个 URL 的耗时对比（串行 vs `gather`）+ 输出落成 JSON 文件并能读回。

## 今日沉淀

| 领域 | 内容 | 关键判据（可复测） |
|---|---|---|
| **`if` 的位置决定语义** | 写在 `for` 后面 = **过滤**（安检门，会丢元素）；写成最前面的三元 = **分流**（进来的都要，长度不变）；前置三元**必须带 `else`**，否则 `SyntaxError` | 同输入 `[1,2,3]`：后置过滤长度 **1**、前置分流长度 **3** |
| **多重 `for` ≠ 嵌套推导式** | `[n for row in m for n in row]` 压平成一层；`[[n for n in row] for row in m]` 保持两层。区别在**产出物本身是不是推导式**，不在 `for` 的个数 | 书写顺序 = 等价双层循环顺序（外层先写）；写反 → **`NameError`**（不是 `TypeError`，因为最左 `for` 的可迭代对象在**外层作用域**求值，那时名字还没绑定） |
| **推导式的独立作用域** | 除最左 `for` 的可迭代对象外，整个推导式在**独立隐式嵌套作用域**执行 ⇒ 迭代变量不泄漏；`for` 语句**会**泄漏 | `n = 0` 后跑 `[n for n in range(3)]` ⇒ `n` 仍 **0**；`for n in range(3)` 后 `n` = **2** |
| **PEP 709（3.12）已内联** | list / dict / set 推导式**不再创建独立函数帧**，隔离语义未变（`LOAD_FAST_AND_CLEAR` 保存/恢复外层同名变量）。微基准 ≈ **1.96x**、pyperformance ≈ **11%** | ⚠️「推导式编译成独立 `<listcomp>` 帧」是 **3.12 前**的老说法，今天查证时当场纠正 |
| **dict 推导式的两条暗规则** | **3.8 起 key 先于 value 求值**（之前未定义，CPython 实为先 value 后 key）；**重复键静默覆盖、不报错** | 值写变量名 = 存引用（`got["a"] is sample[0]` → **True**）；写 `dict(item)` 才是副本。想守住重复键只能数条数（`len(got) == len(items)`） |
| **空容器的字面量歧义** | `{}` 是空 **dict**；空 set 只能 `set()`。但**空推导式 `{x for x in []}` 返回 set** —— 字面量才歧义，推导式看花括号里有没有冒号 | `type({}) is dict` → True；`unique_domains([]) == set()`；`{} == set()` → **False** |
| **切片：新对象 ≠ 深拷贝** | ① 切片**永远返回新容器**（原容器不动）② 新容器装的是原元素的**引用** ⇒ `a[:]` 是**浅拷贝** | `rows[:]`：外层 `is not`、内层 `is` **相同**；改内层 `rows[0].append(99)` ⇒ 原列表跟着变 |
| **半开区间在"缝"上** | `s[i:j]` 选的是从第 `i` 条缝到第 `j` 条缝；`stop` 缺省值 = `len(s)`（末尾**之外**一条缝）⇒ **省略 stop 反而包含最后一个元素**，想排除才写 `[:-1]` | 5 个元素有 **6 条缝**；`n[3::-1]` → `[3,2,1,0]`（含 0）vs `n[:-1]` → `[0,1,2,3]`（不含 4） |
| **负步长的 stop 折算** | ⚠️ `n[3:-1:-1]` 是 **`[]`** 不是 `[3,2,1]` —— 终点位置的 `-1` 照样按 `len-1` **折算**成 4，方向就反了；想到头必须 `n[3::-1]` 或 `n[3:None:-1]` | 切片唯一会报错的输入是 `k == 0`（`ValueError: slice step cannot be zero`）；越界一律**截断**不报错（`[1,2,3][1:100]` → `[2,3]`），索引越界才 `IndexError` |
| **切片赋值 vs 扩展切片赋值** | `s[i:j] = t`（`k=1`）**原地改 + 长度可变**；`k != 1` 时 **`t` 必须等长**，否则 `ValueError`；切片赋值**不是表达式**，拿不到返回值 | `[1,2,3,4,5]` 的 `[1:3] = [9]` ⇒ `[1,9,4,5]` 且 `is` 原列表；`s[::2] = [1,2,3]` ⇒ `ValueError` |
| **可迭代 vs 迭代器** | 可迭代 = 能给你游标（有 `__iter__`）；迭代器 = **自己就是游标**（`__iter__` 返回**自身** + `__next__`）⇒ 迭代器**一定**可迭代，反之不成立 | `iter(it) is it` → **True**；`for` 背后 = `iter()` → 反复 `__next__()` → 捕 `StopIteration`（**不是错误，是协议信号**） |
| **迭代器一次性** | 同一个迭代器 `list()` 两次 → 第二次 **`[]`**，**且不报错**。列表没这问题（每次 `iter()` 造新游标） | `list(it)` → `[1,2,3]` 然后 `[]`；`list(nums)` 两次都 `[1,2,3]` ⇒ 函数把迭代器当容器遍历两遍会**静默空** |
| **生成器三自动** | 函数体出现 `yield` ⇒ 变成生成器函数（调用**不执行**函数体，只返回生成器对象）；`__iter__` / `__next__` / `StopIteration` **全自动**，局部变量与执行位置自动保存 | `g = count_to(2)` 创建时零执行；`next` 三次 → `1` / `2` / **`StopIteration`**（且后续继续抛，官方"broken"条款） |
| **`yield from`（PEP 380）** | `for` 里只有一句 `yield` 时 Ruff 报 **`UP028`** 建议替换；语义相同但**在 C 层委托**（少一层 Python 循环），且能透传 `send()` / `throw()` / `StopIteration.value` | `count_to(3)` 用 `yield from range(1, n+1)` 仍产出 `[1,2,3]` |
| **`__next__` 的停止条件** | 要判**「低于下界」**（`current < 1`），不是「等于最后一个合法值」（`<= 1` 会把 1 当结束标志） | `Countdown(3)`：`<= 1` ⇒ `[3, 2]`（**无异常**）；`< 1` ⇒ `[3, 2, 1]` |
| **工具链三条** | ① `uv run --no-project ruff` 报 `Failed to spawn`（无工程环境）⇒ 用 **`uvx ruff`** ② **`ruff check` 绿 ≠ 格式合规**：顶层两空行（`E302`）不在默认规则集，只有 `ruff format` 管 ③ 静态分析会**挡在判据前面**（`PLE0643` 常量越界下标、Pylance 对 `len(迭代器)` / `迭代器[0]` 报错）⇒ 用变量下标 / `cast(Any, ...)` 擦类型，**别用 `noqa` 糊过去** | 今天 **3 次**踩 `E302`、**1 次** `PLE0643`、**2 条** Pylance `reportArgumentType` / `reportIndexIssue`，全部修净后诊断 **0 条** |
| **回访清单 +3** | #38 迭代器一次性 ｜ #39 负步长 stop 折算 ｜ #40 `__next__` 判下界 | 活跃 **26 → 29**（表头与表格实测行数一致） |
