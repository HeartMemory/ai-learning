# 2026-11-04（周三）· S0·OOP 与协议：`@dataclass` 是生成器，`Protocol` 是名单核对

## 三句话复盘

1. **最大收获**：今天把「**结构约束**」与「**检查约束**」分开了 —— `field(init=False)` 是**结构**（派生字段压根不进 `__init__` 签名，调用方**传不进来**，`TypeError`），`__post_init__` 里 `raise ValueError` 是**检查**（值进来了才拦）。同时看清"检查"还分三层：**注解**（没人管）→ **静态检查器**（Pylance 报红，只是提示）→ **运行时**（解释器不管）。`@dataclass` 与 `Protocol` 都停在第二层，想真守门只能自己写。
2. **最大教训**：**两次「判据 5/5 绿」都是假的** —— `main()` 里那句 `print` 是**硬编码字符串**，函数缺断言它照样印绿。最直接的证据是 ruff **连续三轮**报同一个 `F401 FrozenInstanceError imported but unused`：那个 import 没用上，说明判据 5① 从没写过。立了新规：**绿必须能被变异测试变红**，今天 5 次变异全部变红才算数（见下）。
3. **明天第一步**：**函数与模块**（`*args / **kwargs`、闭包、装饰器、`import`）—— 11-03 被 httpx 挤掉的 D3 缺口还没补。判据 = **自己写一个计时装饰器套在函数上（不查 AI）** + 说清不写 `functools.wraps` 会丢什么。S0 交付物死线 **11-06 不动**；**D3 未补 ⇒ 交付日不提前**（提前口径要求 S0 四条判据全绿）。

## 今日沉淀

| 领域 | 内容 | 关键判据（可复测） |
|---|---|---|
| **`@dataclass` 是什么** | **代码生成器**（≈ C# `record`）：按字段顺序生成 `__init__` / `__repr__` / `__eq__`（`order` 才给比较家族、`frozen` 注入 `__setattr__`）；返回**同一个类**（`slots` 除外） | `Plain("a")` 两实例 `==` True / `is` False / `repr` 含 `name=` |
| **注解不是门禁** | 除 `ClassVar` / `InitVar` 两处，**完全不检查注解类型**。编辑器红字是 Pylance 的**静态**分析（`reportArgumentType`），与运行无关 | `Plain(name=123)` **构造成功**（3.14.8 实测 `P(name=123, n=0) int`） |
| **`__post_init__`** | 生成的 `__init__` **末尾**调它；自己写 `__init__` 或 `init=False` 时不调；`replace()` 走 `__init__` 所以也会跑。顺序必须**先校验后派生**，否则拿非法输入算出"看着正常"的脏值 | `TokenUsage(38, 58).total_tokens == 96`；`TokenUsage(-1, 0)` → `ValueError` |
| **`field(init=False)`** | 派生字段不进 `__init__` 参数表 ⇒ 签名层面堵死"分量与总数自相矛盾"的对象；代价 = **无默认值时必须由 `__post_init__` 赋值**，否则构造成功、`repr` 才 `AttributeError` | `inspect.signature` = `(a: int)`；`C(4, 999)` → `TypeError` |
| **可变默认值** | 默认值挂在**类属性**上（同第 3 章默认参数陷阱）⇒ 必须 `field(default_factory=list)`；3.11 起判据 = 「不可哈希即禁」，**装饰时**抛 `ValueError` | `@dataclass class Bad: xs: list = []` → `mutable default ... not allowed` |
| **`default_factory` 的边界** | 只在**没传值**时调一次；**没有任何类型强制**（传 `list` / `tuple` / `None` 都行，报应延后到用 `list` 方法那一刻）；不能与 `default` 同时给 | 带计数器工厂：显式传值时调用次数不增；`field(default=[], default_factory=list)` → `ValueError` |
| **`frozen=True`** | 伪不可变：注入 `__setattr__` / `__delattr__`，抛 `FrozenInstanceError`（`AttributeError` **子类**）。三边界：**浅冻结**（内层 `list` 可 `append`）、`object.__setattr__` **可绕过**、`frozen` 只**允许**生成 `__hash__`（字段塞 `list` 则 `hash()` 仍 `TypeError`） | 赋值 → `FrozenInstanceError`；同值进 `set` 只剩 **1** 个；`hash(s)` → `unhashable type: 'list'` |
| **`Protocol`** | **结构化**子类型（PEP 544）：形状像就算，不用继承、不用 import。**默认只在静态层生效** ⇒ 未加 `@runtime_checkable` 时 `isinstance` 直接 `TypeError` | `isinstance(Duck(), Raw)` → `TypeError` |
| **`runtime_checkable`** | 只查"**成员名在不在**"，不查签名、不查类型，且明显更慢；数据成员也按"存在"算；可检查性**不被子协议继承**；3.12 起改用 `getattr_static`、成员运行时冻结；3.15 起隐式用法弃用 | `Pretender.close(self, force: bool) -> int`（签名全错）**照样 `isinstance` True**；缺 `name` 的 `NoName` 不通过 |
| **`__dunder__` = 语言协议** | 特殊方法由**类型**决定（`len(x)` → `type(x).__len__`），不需要继承任何东西 ⇒ 与 `Protocol` 同源的"内建版" | `Counter(3)`：`len 3` / `[1, 2, 3]` / `2 in` 真 / `9 in` 假 |
| **`__iter__` 与一次性** | `__iter__` 每调一次**新建**生成器 ⇒ 实例可重复迭代；缓存到 `self._it` 则第二次 `[]`（第 6 章那条的实战版）。`yield` 让函数变生成器函数：**调用不执行函数体**，错误随之后移 | `list(c)` 两次都得 `[1, 2, 3]`；缓存版第二次 `[]` |
| **`__exit__` 的返回值** | `with` 等价于 `except: if not exit_(...): raise` ⇒ **真值吞、假值放行**；正常退出时三参数全 `None`（仍会调）。`...` 是 `Ellipsis` 且为**真值** ⇒ 实现类里留 `...` 会静默吞掉所有异常 | True → 体内 `ZeroDivisionError` 被吞、后续语句照跑；False → 异常放行被外层接住 |
| **异常三联** | `exc_type` 是**类**、`exc` 是**实例**、`tb` 是 `TracebackType`（`traceback.format_exception` 用它）；声明用 `BaseException`（`KeyboardInterrupt` 也不属于 `Exception`） | `format_exception(exc_type, exc, tb)[-1]` → `ValueError: 我故意的` |
| **`assert` 的失效条件** | `python -O` 把**所有** `assert` 语句整条删掉 ⇒ **库里的输入校验必须 `raise`**；练习判据用 assert 无妨。ruff **B011** 禁 `assert False`，反例改用 `try/except/else` + `raise AssertionError` | `python -O -c 'assert False; print("照跑")'` → print 照跑 |
| **工具链四条** | ① 3.14 起注解引号多余（PEP 649）⇒ ruff **UP037** ② 裸 `1 / 0` 被 **B018** 判无用表达式 ③ `except X: pass` **后接 `else` 时 SIM105 不触发** ④ 故意违规的代码用 `# noqa: RUF008` / `# pyright: ignore[...]` **精确静音**并注明"刻意" | `ruff check` + `format --check` 双绿 |
