# 2026-11-26（周四）· L3 关卡 0 基线可复现

## 三句话

1. **最大收获**：**seed 只固定「抽到哪些随机数」，不固定「浮点按什么顺序相加」**。同一份代码、同一个 seed 连跑两次：前 40 步逐步 CE 差 < 1e-9，第 **40** 步起出现 **1e-06** 的差，一路放大到 **1.944e-02**（step 1236），终值 val CE 差 **6.397e-03**（1.806031 vs 1.799635）—— 1400 步里 **1371 步**有差。
2. **最大教训**：**要复现就得付确定性的价钱，而那个价钱得量出来**。开 `CUBLAS_WORKSPACE_CONFIG=:4096:8` + `use_deterministic_algorithms(True)` + `cudnn.benchmark=False` 后，逐步差与终值差都是**严格 0**（0/2000 步有差，1.801704860 == 1.801704860），且跨独立进程仍复现；代价 = 显存 **0.322 → 0.368 GiB（+14.3%）**，耗时 **测不出来**（同一路径 30–50 s 抖动）。
3. **明天第一步**：L3 **关 1「lr」**——五档 `{1e-5, 1e-4, 3e-4, 1e-3, 1e-2}`，要拿到「不动 / 稳降 / 发散」三种形态各至少一档；**一律在确定性模式下跑**，噪声门限 **0.019560**。

## 今日沉淀

### 复现性分三层，只有第一层归 seed 管

| 层 | 由什么决定 | 本关实测 |
|---|---|---|
| 随机数序列（初始化 / 抽样） | `manual_seed` + 独立的 `Generator` | **完全一致**：前 40 步逐步 CE 差 < 1e-9 |
| 浮点累加顺序 | GPU 上 `atomicAdd` 的线程竞争顺序，**seed 管不到** | 第 40 步起差 **1e-06** |
| 训练动力学（混沌放大） | 上面那一丁点差被 2000 步放大 | 1e-06 → **1.944e-02**，放大 4 个数量级 |

本模型里两个已知的原子累加点：`nn.Embedding` 反向（词表只有 65 个字符，一个 batch 里几千个 token 往同一行梯度上累加）与 SDPA flash 反向的 dQ 累加（PyTorch 2.13 博客明确）。

**为什么判据必须「逐步」比**：终端打印 4 位小数时前 600 步两组曲线一模一样，只有按 1e-9 逐行比才看见 step 40 就已经分叉；而终值 6e-03 这个量级，很容易被误读成「评估蒙特卡洛噪声」。

### 确定性开关三件套

| 开关 | 作用 | 为什么必须 |
|---|---|---|
| `CUBLAS_WORKSPACE_CONFIG=:4096:8` | 给 cuBLAS 一块固定大小的工作区 | CUDA ≥ 10.2 且用 cuBLAS 时**不设它，下一行一开就报错**；且必须写在 `import torch` **之前** |
| `use_deterministic_algorithms(True)` | 让原子累加类算子改走「分桶 / 排序后累加」的确定实现 | 全局总开关；遇到**没有**确定实现的算子直接抛 `RuntimeError`（本机没抛，说明这条路径上的算子都有确定实现） |
| `cudnn.benchmark=False` + `cudnn.deterministic=True` | 关 autotune、只用确定算法 | autotune 会让不同 run 选到不同算法（本模型无卷积，实际不参与，但口径要写全） |

**代价的实测**：显存 **+46 MiB（+14.3%）** 是稳定可测的；耗时在**同批**内无法区分（同一条路径六次：30.4 / 30.5 / 33.4 / 35.3 / 43.7 / 47.0 s —— 首跑要付 kernel 预热与时钟爬升的账）⇒ 「确定性模式慢多少」在这台机器上用耗时是量不出来的，只能报显存。

### 噪声带 = 后面四关的地板

| seed | val CE |
|---|---|
| 1337 | **1.801705** |
| 2024 | **1.782145** |
| 7 | **1.789220** |
| **极差** | **0.019560** |

3 个 seed 的极差 **0.019560 nats/char**（约 1.09 % of 1.80）就是门限：关 1–4 里任何「变好 / 变坏」超过它才算信号，小于它一律记「在 seed 噪声内」。带子里**只含 seed 噪声**，不含「同 seed 重跑噪声」—— 后者在确定性模式下已经被压成 0。
