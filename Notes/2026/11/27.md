### 2. 工具调用能力（一次探针，¥0.0001）

`probe_tools.py` 输出：

```

tool_calls[0]  = id=call_324c… · name=get_time · arguments='{"city": "北京"}'
```

三个从输出读出来的事实（写循环全靠它们）：
1. `arguments` 是 **JSON 字符串**，不是 dict ⇒ 必须 `json.loads` ⇒ 也就必然存在"模型给非法 JSON"这条异常路径；
2. `tool_calls` 是**数组**且元素带 `index` ⇒ 结构上按"可能多个"设计，不能只取 `[0]`；
3. 一个工具 schema + 一句短问已经 **303 input token** ⇒ agent 每轮重发全史，总 token 随步数增长。

### 3. 商用 harness 的权限模型（五家交叉）

| 产品 | 模型 | 关键事实 |
|---|---|---|
| OpenAI Codex | **沙箱 × 审批** 两轴 | `on-request`：沙箱内直接跑，**越界/联网/动沙箱外文件才问**；`never`：不问但边界仍在；`danger-full-access`：取消边界。默认 `workspace-write + on-request` |
| Claude Code | allow / ask / deny | **按「拒绝 → 询问 → 允许」顺序匹配，第一个命中即决定**；宽 deny 不能被更细的 allow 例外绕过；另有沙箱化 Bash（OS 层强制文件系统边界） |
| Cursor | Run Modes + `Shell(commandBase)` | `commandBase` = 命令行第一个词，支持 glob / `command:args`；Auto-review 为推荐默认 |
| Gemini CLI | approval + `--sandbox` | 两层独立刹车，写操作与 shell 默认需确认 |
| DeepSeek Harness（dsh） | **preset = mode + approval 打包** | 原文：「**它不是沙箱，真正的文件访问边界在沙箱**」；`dsh-sandbox-local` 按平台选后端：Linux bwrap/Landlock、macOS Seatbelt、**Windows ACL 受限令牌**；无后端时 **fail-closed**（`SANDBOX_UNAVAILABLE`），不裸跑 |

三条从事故/源码里学到的：
- **白名单粒度错一个字就全漏**：某客户端把裸域名 `huggingface.co` 写进预批准名单 ⇒ 该域名任意路径都不提示（CVE-2026-54316）。
- **三档只管控文件效果，不管网络**：实测/源码分析指出 `read-only` 档的插件照样能连外网。
- **`danger-full-access` 不走沙箱**：consumer 直接 `spawn` 原始 argv，只有前两档会被 `confine()` 包装。

### 4. 语言层三条

- **`from __future__ import annotations` 在 3.14 是"例外路径"**：PEP 649/749 让注解默认**延迟求值**（实测 `def f(x: NoSuchName)` 定义时不报错），而 future 导入会把注解**强制成字符串**、绕过新机制 ⇒ 没有前向引用就不该加。
- **`__file__` 与 cwd 的区别**：`Path(__file__).resolve().parent` 与启动目录无关（实测项目内 / 仓库根两种 cwd 下 `PROJECT_ROOT` 不变，`cwd` 会变）；`load_dotenv()` 裸调用按 cwd 找文件 ⇒ 必须显式传路径。
- **`dir` / `type` / `echo` 不是 exe**：`where dir` 无输出（`cmd.exe` 内置）⇒ `subprocess.run(["dir"], shell=False)` 直接 `FileNotFoundError`；要用只能 `cmd /c`，但那把 shell 的注入面拉回来了。

## 四、决策（写下来，防明天重新争论）

1. **L5 底座 = 三档预设 + 命令白名单 + 路径校验**，但档位语义照抄 dsh（`read-only` / `workspace-write` / `danger` × `on-request` / `never`），并且在**没有沙箱后端时明确标注 `sandbox_backend=none`**，不假装有边界。
2. **命令白名单最终版**：`git status|diff|log` + `findstr`。`python` 撤掉（图灵完备的解释器一进白名单，白名单即失效）；`where` 砍掉（几乎无用，纯增口子）；`dir` / `type` / `echo` 因不是 exe 且必须 `cmd /c`，不采用 —— 列目录改由自己的 `read_file` 工具承担。
3. **子进程 env 白名单**：`LLM_API_KEY` 永不进子进程（这一条比沙箱更关键 —— 沙箱管写不管读）。
4. **沙箱单独立项**：先做 `probe_sandbox.py`（合成 SID + `CreateRestrictedToken` + `CreateProcessAsUser`），四条判据 **A 沙箱内写成功 / B 沙箱外写拒绝 / C 反向对照（不开令牌写外部应成功）/ D 子进程 env 无 key**，外加 fail-closed 一条；S1 绿了才谈把它接进工具层（S2/S3），再接回 L5 判据（S4）。
