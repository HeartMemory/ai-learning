# 2026-11-24（周二）· L2 关卡 3：最小 block

## 三句话

1. **最大收获**：一个 block 是**三件缺一不可**的东西拼起来的 —— LayerNorm（跨特征把每个 token 拉回标准形态）、残差（保尺度、给梯度留直通路）、FFN+GELU（**唯一的**逐点非线性）。实测证据：去掉 GELU 后 `C→4C→C` 两层线性等价于**一层**矩阵（差 **8.88e-16**，128 个参数白等于 16 个）；残差让支路只占主项 **0.09%**（0.002 vs 2.31）⇒ 初始 block ≈ 恒等映射。
2. **最大教训**：**判据全绿 ≠ 判据有牙**。第一版判据 ①（形状 / 参数量 / ×1000 有界）在三个变异下**全部漏网** —— 方差改成无偏（`correction=1`）、EPS 挪到开方外、残差被删掉，判据一律绿。补了 **D（与官方 `nn.LayerNorm` 逐元素对账，含 `var≈1e-6` 的小方差输入）** 与 **E（`|out|/|in| ∈ [0.5,2]`）** 之后 4/4 全红。最狠的是 M3：**gradcheck 也抓不到**（去掉残差后函数依然处处可微）。
3. **明天第一步**：L2 关卡 4「真训练」—— tinyshakespeare 2000 步、峰值显存 < 6 GiB、**val CE 严格低于 bigram 基线 1.2943 bits**。先搭数据管道与训练循环的框架，`max_memory_allocated` 的报数要单独验。

## 今日沉淀

### 三个方向，互不重叠

| 组件 | 沿哪一维 | 干什么 |
|---|---|---|
| attention | 跨 **T** | 混合信息（加权平均，仍是线性） |
| LayerNorm | 跨 **C**，每 token 独立 | 把向量拉到半径 √C 的球面（实测行范数 1.99999…，√4 = 2） |
| FFN + GELU | 逐 token，谁都不跨 | 唯一的逐点非线性 |
| 残差 | 同位置、同维度直接相加 | 保尺度 + 梯度直通 |

因为方向不重叠，残差才能一路直加不打架。**尺度能线性传下去**也靠残差：输入 ×1000 ⇒ block 输出 absmax 从 2310.41 跟着变 2310.41，而 LN 支路是尺度无关的（权重矩阵差 6.37e-08）。⇒ 判据只查「LayerNorm 输出有界」，**不查 block 输出有界**，这是有原因的。

### LayerNorm 的四条口径（全部实测）

| 口径 | 事实 | 数字 |
|---|---|---|
| 方差分母 | **有偏**（= `correction=0`），不是 Bessel | 与官方差 **2.22e-16**；与 `correction=1` 差 **0.2146**（C=4 时 var 比 4/3） |
| ε 的位置 | 加在**方差里**再开方 | `sqrt(0 + 1e-5)` 让常数输入得 0 而非 NaN；写成 `sqrt(var) + EPS` 后 var=0 处梯度仍是 `inf` |
| 输出方差 | 不是 1，是 `var/(var+ε)` | `[1,2,3,4]` → **0.999992**；`[0.1,0.2]` → ±**0.998**（差 0.2%） |
| 单元素上界 | **√(C−1)** | `[0,0,0,5]` 归一化 = `−0.577×3` 与 **1.732 = √3** —— 正好是取到上界的形状 |

⇒ 「归一化后每个 token 落在半径 √C 的球面、且垂直于全 1 方向；γ/β 再把长度和偏移还回去」。

### 判据补强：今天最重要的方法

| 变异 | 改坏什么 | 第一版判据 | 抓它的项 |
|---|---|---|---|
| M1 | `correction=0 → 1` | **全绿（漏网）** | D：与官方差 随机 2.289e-01 / 小方差 8.059e-03 |
| M2 | `sqrt(var+ε) → sqrt(var)+ε` | **全绿（漏网）** | D：小方差 **8.825e-01**（随机输入只差 7.58e-05） |
| M3 | 去掉 `x +` 残差 | **全绿（漏网）** | E：`|out|/|in|` = **0.0006**（正常 1.0004） |
| M4 | CE 用 `.sum()` | ② C 红 | 手写 14.47 vs 官方 2.41 |

两条经验：

1. **「有界」类判据抓不到「口径错」** —— `correction=1` 只是让输出从 1.7083 掉到 1.4795，仍落在 `[1.0, √3]` 里。判「口径」必须用**独立参考实现逐元素对账**。
2. **小方差输入是放大器** —— ε 位置写错时随机数据只差 7.58e-05（看不见），`var≈1e-6` 时才放大到 0.88（一眼红）。⇒ 边界用例要按「哪个量会暴露这个 bug」来设计，不是随便造。

### gradcheck 的两条前提

- **只吃 float64**：float32 的有限差分噪声相对 ~3e-4，与默认 `rtol=1e-3 / atol=1e-5` 同量级 ⇒ 写对写错都可能随机红绿。
- **必须把参数也当输入**：`gradcheck(f, (x,))` 只验了 `d输出/d输入`；16 个参数一个都没查。用 `functional_call` 把 54 个参数元素 + 6 个输入（共 **60 个入参**）一起喂进去。

### CE 梯度：反传的第一环

$$\frac{\partial\,CE}{\partial\,\text{logits}}=\frac{\text{softmax}-\text{onehot}}{N}$$

- `softmax − onehot` = 每格「该涨还是该跌」，真类那格为负；除以 `N` 因为 `reduction='mean'` 对**样本**平均（不是 `N×V`）。
- **每行梯度之和恒为 0**（实测 3.166e-17）—— softmax 概率和为 1 ⇒ 只有相对值有意义。
- 交叉熵的三个口径：**onehot 硬标签 + 自然对数（nats）+ 按样本平均**。L1 的 1.2943 是 bits/char（`log2`），两者差 `ln2`；`ppl = exp(CE_nats)`。

### bias 在单头注意力里的真实地位（顺带查清）

| 参数 | 实测效果 | 结论 |
|---|---|---|
| `bk` | 权重差 **5.55e-17** | **完全无效** —— softmax 平移不变，`bk` 只给每行加同一常数 |
| `bv` | 与 `bo=bv@wo` 输出差 **4.44e-16** | **冗余** —— 行和为 1 ⇒ 退化成常数 |
| `bq` | 权重差 **0.077** | **有效** —— 等于给每个 key 一个固定加分 |

**注意力的"参与"由 softmax 权重 + 掩码决定，bias 不是门槛**；真正像门槛的是 FFN 里 GELU 之前那个 `b1`（把激活切入点整体平移）。

### `gather` / `unsqueeze` / `logsumexp`

- `logsumexp` 内部做 max-shift：朴素 `log(exp(1000).sum())` 直接得 `inf`，它有 **1000.6931**（= 1000 + ln2）。
- `gather` 三条硬约束：`index.ndim == input.ndim`、dtype int64、值在 `[0, size(dim))`。`targets (N,)` 必须先 `unsqueeze(-1)` 成 `(N,1)`，取完 `squeeze(-1)` 回 `(N,)`。
- 输出形状**只由 `index` 决定**，与 `input` 没有直接相等关系。
