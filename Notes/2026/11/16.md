# 2026-11-16（周一）· L1 关卡 1：语言模型的第一层不是「模型」，是数票 + 换算成比例

## 三句话复盘

1. **最大收获**：`P(下一个字 | 上一个字)` 一点不神秘 —— 分母是**行和**（这个字当 context 出现了几次），不是语料总对数。所以 `P(包|面)=1.0` 而全局 `P(包)=0.0213`：同一个事件在两种分母下差出 **47 倍**。由此看懂了 char-level 的取舍：词表只要 **180** 个（不用分词器），代价是「要吃很长的上下文才能攒出词级信息」。
2. **最大教训**：**判据要分「不变量」和「区分器」**。`sum(counts.values()) == len-1` 是不变量 —— 把「按 context 聚合」写成「按 next 聚合」时它**照样绿**；只有逐字符的行和自证（`row_totals[c] == TEXT[:-1].count(c)`）才逼得出来。同一道理在变异 M2 上更狠：让 `next_probs` 直接返回全局分布，归一判据 ① 的「和」**全绿**（仍是 1.0），当时唯一抓得住它的是判据 ②；加固后 ① 的「键集合」断言也能拦在前面。
3. **明天第一步**：L1 关卡 2（交叉熵 / 困惑度）—— 在训练集上报 `log2(V) > CE_unigram > CE_bigram` 三个数（bits/char），再切后 20% 当留出集，看 bigram 的 CE 是不是被稀疏顶上去。

## 今日沉淀

| 领域 | 内容 | 关键判据（可复测） |
|---|---|---|
| **bigram 计数** | 每个起始位置 `i ∈ [0, n-2]` 贡献一对，内容相同的合并成一种 | 总对数 **421** = `len - 1`；不同 bigram **350** 种 |
| **行和的正确聚合** | 按**前一个字**聚合，不是按后一个字 | `row_totals['，']=28`；改成按 next 聚合 ⇒ 判据 ① 仍绿、② 红（`'。' 给了 14，语料里 13 次`） |
| **末位与首位** | 末位字符**不当 context**（后面没字）、首位字符**不当 next**（前面没字）；中间每个字各参与两次 | `TEXT[:-1].count('。')=13` vs `TEXT.count('。')=14`；键集合 = `set(TEXT[:-1])` |
| **条件概率定义** | `P(next\|ctx) = 该对次数 / 行和[ctx]`，不是除以总对数 | 每个 context `Σ P == 1.0`（±1e-12）；用总对数当分母则和 ≈ 1/90 |
| **条件 ≠ 边际** | 条件分布只在少数几个字符上有值，全局分布在 180 个字符上都有值 | `P(包\|面)=1.0` vs 全局 `0.0213`（差 **0.9787**）；`'猫'` 9 种后继、最大差 **0.1087** |
| **两分布相减的边界** | 键集合不同，必须 `probs.get(c, 0.0)` | 直接 `probs[c]` 遍历全局键 ⇒ `KeyError: '。'` |
| **判据阈值不能拍脑袋** | 「出现了最多的两个字 + 差 > 0.10」实测只有 **0.1087**，勉强压线；换语料就假红 | 改选「后继种类最少」的 context：`'面'` 9 票全给 `'包'`，差 **0.9787**，与语料规模无关 |
| **未见 context** | 返回**空 dict**，不抛 `KeyError`；空分布的和是 0.0，不为 1 | 删掉守卫 ⇒ `KeyError: 'a'`（变异 M3 红） |
| **`get(k, 0)` 的 0** | 是**加法单位元**：第一次见到该键时 `0 + count = count` | 默认值给 `1` ⇒ 总票 **421 → 601**（180 个 context 各多一票）；不给 ⇒ `TypeError: NoneType + int` |
| **dict 迭代给键** | `for x in d` 拿的是键；要键值对只能 `d.items()` | `next(iter(counts))` → `('清', '晨')`；双层解包直接迭代 ⇒ `ValueError: not enough values to unpack` |
| **`set` 顺序不可依赖** | 字符串 hash 每进程随机化 ⇒ 同一份语料两次跑出不同顺序 | 3 次独立进程：`crc32(sorted(set))=1004191269` 恒定，而 `list(set)[:12]` 三段全不同 |
| **`sorted(iterable)`** | 直接吃 set（参数就叫 iterable），返回新 list；`list()` 是多余的 | `sorted(set(text))` ≡ `sorted(list(set(text)))` |
| **断言消息** | 要**收敛信息量**：报关键数字，不打印整个容器 | 打印 180 键的 dict ⇒ 一片滚屏、等于没信息；只报「键数 + 关键键的值」即可 |
| **`!r` 转换** | 在格式化前先 `repr()`，让不可见字符现形 | `{' '!r}` → `' '`、`{'\u3000'!r}` → `'\u3000'`；`{x!r:>10}` 合法、`{x:>10!r}` 非法 |
| **判据样本与阈值（同日最终口径）** | 判据里**不写字面量、不设阈值**：自动挑「出现 ≥3 次且后继唯一」的 context，断言点质量 + 恒等式 `最大差 == 1 − P_global(唯一后继)` | ⚠️ 上一条的「后继种类最少」会把只出现 1 次的字挑进来（`'清'` 后继唯一但只见过 1 次）—— 退化样本，什么也没证明。最终版实测：`'面'→'包'`，`0.9787 == 1 − 0.0213` |
