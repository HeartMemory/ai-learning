# 2026-11-18（周三）· L1 关卡 3：softmax —— 数学上等价，浮点上生死

## 三句话复盘

1. **最大收获**：`softmax(z+c) ≡ softmax(z)`（分子分母同乘 `exp(c)` 约掉）⇒ `c` 是**自由参数**，选 `c = -max(z)` 之后 `u_i ≤ 0` 恒成立、`exp(u_i) ∈ (0, 1]`、分母里必有 `exp(0) = 1` ⇒「向上溢出」和「0/0」在结构上不可能发生。实测：平移误差 **0.00e+00**（c ∈ {1, −5, 100} 逐位相同），稳定版↔naive 互证 **6.78e-21**。
2. **最大教训**：**变异测试暴露的是判据的「输入形状」漏洞，不是实现的错**。M2（减 mean）/ M3（减首项）第一轮**全绿** —— 因为原极端输入 `[1000, 0]` 的首项恰好是 max、`mean` 位移只到 500（`exp(500) ≈ 1.4e217` 还在安全区）。补 `[0, 1000]`（首项是最小值）与 `[1e6, 0]`（差值 1e6 ⇒ 位移后仍剩 5e5）才红。**断言条数不等于判据强度。**
3. **明天第一步**：L1 关卡 4（平滑）—— 未见 bigram 让 CE = `inf`（昨天已实测 67/84 = 79.8% 未见对），add-k（k = 1 / 0.1）后变有限且可比；判据 = `inf` → 有限 + add-1 与 add-0.1 各报一个数。

## 今日沉淀

| 领域 | 内容 | 关键判据（可复测） |
|---|---|---|
| **softmax 定义** | `exp(z_i) / Σ exp(z_j)`；先保证恒正，再归一 | `[0,0]` → `[0.5, 0.5]`、`[7.5]` → `[1.0]` |
| **平移不变的来源** | 分子分母同乘 `exp(c)` 后约掉 —— **恒等式**，不是近似 | 加 1 / −5 / 100 后最大差 **0.00e+00** |
| **为什么是 max（唯一选择）** | 要保证 `u_i = z_i − m ≤ 0`，就必须 `m ≥ 所有元素`；满足这个条件的最小值就是 max（保最大动态范围）。减比 max 更大的数虽然也行，但会把小项压到下溢 | `[1e6, 0]` 减 max → 正常；减 mean（5e5）→ `OverflowError` |
| **为什么不能减 mean / 首项** | 它们**没有保证**：`[1e6,0]` 的 mean 位移后仍剩 5e5（`exp(5e5)` 爆）；`[0,1000]` 的首项是 0（`exp(1000)` 爆）。平移不变判据**抓不到**这两种错（它们也是合法的平移） | 这两条输入是唯一能区分的用例 |
| **`exp` 的可用区间** | 约 `[−745, 709]`：`exp(709)` = 8.218e+307，`exp(710)` → **`OverflowError`**；`exp(-745)` = 5e-324，`exp(-746)` → **`0.0`**（**不抛**） | 上溢抛异常，下溢静默 —— 两种失效模式必须分开测 |
| **两种死法** | naive + `[1000,0]` → `OverflowError`；naive + `[-1000,-1001]` → 两个 exp 都成 `0.0` → **`ZeroDivisionError`** | 同一个「防溢出」问题，两种异常 |
| **下溢 ≠ 减 max 的副产品** | `[0, -800]` 两个版本都给 `[1.0, 0.0]` —— naive 也没溢出，也照样丢。丢弃发生在「连最强者都差 745 个数量级」时，属浮点表示能力，不是算法选择 | `[-1000,-1001]` 差 1 ⇒ 精确 **0.73106 / 0.26894**（= `1/(1+e⁻¹)`） |
| **要救下溢就换坐标** | `log_softmax = z_i − m − log Σ exp(z_j − m)`，全程不 exp 原值 ⇒ `-1000` 能原样保存；PyTorch `Categorical.probs` 的文档明说可能下溢到 0，而 `log_prob` 取 logits 所以永不下溢 | 官方依据见 AI 册第 7 章 |
| **同序 vs 保序** | **同序** = 输出第 i 项属于输入第 i 项（靠逐元素映射结构，白送）；**保序** = `z_i < z_j ⟹ p_i < p_j`（靠 `exp` 单调 + 除同一标量，要主动验） | 同序用**升序输入**的精确值抓（排序实现会露馅）；保序用链式比较 |
| **`[zip(x, x[1:])]` 是假绿** | 多套一层方括号 ⇒ `for a, b in diff` 解包成**两个元组**，比的是**元组字典序**；非单调的 `[0.1, 0.5, 0.4]` 也返回 `True` | 正确写法 `probs[0] < probs[1] < probs[2]` |
| **`zip` 的四条规矩** | 返回迭代器（一次性、无 `len`）；以最短为准**静默截断**；`strict=True`（3.10+）才抛 `ValueError`；`zip(*rows)` 是转置 | `list(zip([1,2,3],[4,5]))` → 2 对；`ruff` 规则 `B905` 强制写 `strict=` |
| **f-string 格式说明符** | `{值:说明符}`：`.2e` = 科学计数法 2 位小数（看误差量级），`.15f` = 定点 15 位（看逐位精确），`.2%` = 百分比 | `f"{2.22e-16:.6f}"` → `0.000000`（这就是误差不能用 `.6f` 的原因） |
