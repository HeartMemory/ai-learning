## 二、失败轨迹（这是今天最值钱的部分）

| 现象 | 病因 | 修法 |
|---|---|---|
| `CreateProcessAsUser` 直接 `WinError 5` | base 令牌只要了 `TOKEN_DUPLICATE\|QUERY`，而新令牌句柄权限 = base 的 | base 改开 `TOKEN_ALL_ACCESS`（0xF01FF） |
| 进程创建成功但立刻死 `0xC0000142` ×N 次 | 限制 SID 只放合成 SID ⇒ 第二遍检查在 WinSta0 / 桌面 全灭 | 补 `logon SID` + `Everyone` |
| 同上，且**任何 SID 组合**都 `0xC0000142` | 令牌**默认 DACL** 里没有限制 SID ⇒ 子进程打不开自己新建的控制台 / IPC 对象 | 重写 `TokenDefaultDacl`，加一条限制 SID 全权 |
| `WinError 87`（参数错误） | 传了 Unicode 环境块但没带 `CREATE_UNICODE_ENVIRONMENT` | 创建标志补这一位 |
| `icacls /grant "*SID:..."` 报 `ERROR_NONE_MAPPED` | icacls 要求 SID **能映射到账户**；`*S-1-5-32-544` / `*S-1-1-0` 能过，合成 SID 不能 | 改用 `SetEntriesInAclW` + `SetNamedSecurityInfoW`（直接吃 PSID，不查账户表） |
| `IsTokenRestricted` 返回 FALSE，但限制 SID 数 = 1 | 该 API 对本场景不可靠（调用本身成功） | 自检改用 `GetTokenInformation(TokenRestrictedSids)` 数 `GroupCount` |
| 日志里有 `No usable temporary directory found` | 沙箱把 `%TEMP%` 挡了，Python 找不到可写临时目录 | 环境白名单里把 `TEMP`/`TMP` 指进 `.sandbox-root` |
| 白名单键数 11 而非 12；中文日志乱码 | 白名单写了 `PYTHONIOENCODING` 但父进程没有这个变量（Python 专用开关，系统不设）⇒ 被跳过 ⇒ 子进程按 gbk 输出 | 在 `DEFAULT_ENV` 的 overrides 里**写死** `PYTHONIOENCODING=utf-8`；并删掉 judge 里重复拼的环境块 |

### 消融实验（定 3 项口径的依据）

| 限制 SID 列表 | 默认 DACL | `whoami` | 写沙箱内 | 结论 |
|---|---|---|---|---|
| `[合成]` | 有 | `0xC0000142` | — | 缺 logon / Everyone 起不来 |
| `[Everyone]` | 有 | `0xC0000142` | — | 缺 logon 起不来（Everyone 替代不了） |
| `[logon, Everyone, 合成]` | 有 | `0` | 成功 | **采用** |
| `[logon, 合成]` | 有 | `0` | `0xC0000142` | `whoami` 能跑但 **Python 起不来** ⇒ Everyone 必需 |
| 任意组合 | **无** | `0xC0000142` | — | 默认 DACL 是必需项，与 SID 组合无关 |

## 三、口径修正（一处，已改进阶段表）

**判据 B 的错误码**：原措辞「`WinError 5`（ERROR_ACCESS_DENIED）」。

实测：Python 的 `open()` 在 Windows 上走 **errno 映射** —— 抛 `PermissionError`，`errno=13`、**`winerror=None`**（`os.mkdir` 这类走 `PyErr_SetFromWindowsErr` 的才给 `winerror=5`）。

⇒ 改成「`errno 13 (EACCES)` / 原文含 `Permission denied`」，内核层面仍是同一个 `ERROR_ACCESS_DENIED`。不改的话 B 会永远红，且红的原因是我们口径写错、不是沙箱没生效。

## 五、边界声明（不许超出声称）

- **只管写，不管读**：`WRITE_RESTRICTED` 让限制 SID 只在写访问时参与检查
- **只约束子进程**：父进程、网络、注册表完全不受限
- **只动一个目录**：`.sandbox-root` 的 DACL；`%TEMP%` 从未被"禁止"，它只是"没被允许"
- ⚠️ **弱点**：`Everyone` 在限制列表里 ⇒ 任何 ACL 对 Everyone 开放写的目录都挡不住。已抽样确认 `C:\Windows\Temp` / `C:\Users\Public` / `%TEMP%` / `C:\` 都无 Everyone 条目，但这是**采样**不是保证
- ⚠️ **日志文件走继承句柄**：写已打开的句柄不再做路径/ACL 检查 ⇒ 「日志能写」不能当作沙箱证据
